# Student Performance Analysis System

## What you are submitting
- `student_performance_analysis.py` — main Python program
- `students.csv` — data file used by the program
- `test_student_performance_analysis.py` — automated tests
- `performance_report.txt` — generated report after running option 6
- `Python_Project_Report.docx` — formatted project report
- `Project_Presentation.pptx` — milestone/final presentation
- `Viva_Cheat_Sheet.txt` — short viva preparation notes

## How to run
1. Install Python 3.9+.
2. Put all files in the same folder.
3. Open Terminal/Command Prompt in that folder.
4. Run:
   `python student_performance_analysis.py`
5. Try menu options 1, 3, 4, 5 and 6.
6. The program automatically creates/uses `students.csv`.
7. Option 6 creates `performance_report.txt`.

## How to run tests
Run:
`python -m unittest test_student_performance_analysis.py`

## What YOU must customize
Replace the following placeholders in the report/presentation:
- Student names
- Enrollment numbers
- Batch / Section
- Team-member responsibilities
- Screenshots, if your instructor wants screenshots from your own machine

## Suggested team division (4 members)
Member 1: CSV/file handling + data entry
Member 2: calculations, grading and ranking
Member 3: subject analysis + report generation
Member 4: testing, documentation and presentation

All members must understand the complete program because the instructions explicitly state that the individual viva may test any function or logic.
