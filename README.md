## Project Description

The Student Performance Analysis System is a Python-based application
designed to manage student marks and analyse academic performance.

The system allows users to:

- Add student records
- Store marks using CSV
- Calculate total and average marks
- Assign grades
- Rank students
- Analyse subject-wise performance
- Identify improvement areas
- Generate performance reports

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder in the terminal.
4. Run:

python student_performance_analysis.py

## Testing

Run:

python -m unittest test_student_performance_analysis.py
